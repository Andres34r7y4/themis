# Task Template — Themis

```markdown
### task
id: AUTO
title: <short imperative title>
impact: high | medium | low
effort: low | medium | high
risk: low | medium | high
depends_on: []

#### Objective
<what must be achieved and why>

#### Definition of Done
- [ ] <verifiable criterion>
- [ ] <verifiable criterion>

#### Probable files
- <real path or "unknown">

#### Verification
- Command: <real command>
- Expected: <observable result>

#### Notes
<any restriction, open question, or TODO>
```

## Rules

- IDs are generated automatically (`YYYY-MM-DD-XX` for cycles, `backlog-XXX` for backlog).
- Maximum 3 active tasks per cycle.
- A task must be atomic and verifiable in one cycle.
- Do not list files you have not verified unless marked as probable.
